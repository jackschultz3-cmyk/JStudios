# Vault guide for Claude

This folder is an Obsidian vault. Notes are plain Markdown; Claude reads and edits them directly.

## Layout
- `Game/` - the game project. `Game/Game Prompt.md` is the source-of-truth design prompt (Project Ascendant).
- `Game/Reference/Original Prompt.md` - superseded franchise-based draft; reference only, do not build from it.
- `Start Here.md` - vault home note.

## Conventions
- Link notes with Obsidian wikilinks: `[[Note Name]]`.
- Put metadata in YAML frontmatter (`tags`, `status`) so Obsidian Properties and Bases can use it.
- Don't edit anything in `.obsidian/` unless asked.

## Graphify
Graphify indexes this vault once it's pushed to a GitHub repo and enabled at https://app.graphify.com.
Use Graphify `recall` / `remember` for durable design decisions; keep the notes themselves in the vault.

## Originality
Project Ascendant is an original IP. Never use characters, names, moves, locations or designs from existing franchises (e.g. Dragon Ball). Genre conventions are fine.
